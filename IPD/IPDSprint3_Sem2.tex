\section{Sprint Retrospective}

\subsection*{Mara}

 I downloaded the cisco vpn, so now I can sign into the ARC without being on campus. 
 In addition, I added a data class to the website, so I can more easily pass it into functions 
 depending on the version. You can now sort by versions, which will be filled in with the 
 proper data in the future. We also planned out more of the website layout, and I started 
 working on filling in the version differences.

\subsection*{Chris}

This sprint I worked on ensuring the model architecture (yes, again) and to refine the 
workings of the model so that it could properly use the data that Tzu-Chen created. I also 
worked on a data packing scheme to more efficiently load the data into the model using a 
data storing format called ``HDF5''. Next sprint, I will fix a few more issues with the model 
and the finally queue training on the ARC. 

\subsection*{Tzu-Chen}

 I have finished preparing the pretraining, fine-tuning, and testing datasets. For pretraining, 
 the new measurement and event files were generated from Google-provided Stim circuits. 
 The dataset split and design are intended to avoid information leakage. Our goal is to train a 
 model with the ability to generalize across \textbf{distance, number of rounds, and basis}. The next 
 step is to convert the data into valid model inputs and design an appropriate embedding 
 strategy for the input dimensions.

\subsection*{Arjun}

This week I assisted Chris and Tzu-Chen with their respective tasks and helped create the 
best method possible to integrate both their work. Through theoretical discussion and pair 
programming, Chris and I worked on the best possible method of getting the data into the 
model and helped randomly sort the data for the best possible results of training the model.
